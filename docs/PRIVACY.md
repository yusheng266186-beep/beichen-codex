# 隐私与安全边界

## 收集与处理

- 页面只要求动态验证码和可选的省份、年级、参考年份、目标偏好；不应输入姓名、联系方式、学校班级、精确住址或其他可识别信息。
- 用户输入会通过独立中转发送给配置的模型供应商，用于生成本轮回复和星图。中转不把对话原文写入日志。
- 只有在序章额外勾选“在本机保留谈话记录 7 天”后，浏览器才会保存结构化谈话文本和报告；不勾选仍可正常使用。数据带 v3 命名空间和过期时间。认证票据只在当前标签页 sessionStorage 中短期存在，关闭标签页即失效。共享设备请在结束时使用“清除本机记录”。
- 云函数默认状态只在实例内存中保存，重启会失效；若接入外部 KV，应另行公布保留期、访问控制和删除流程。

## 未成年人

北辰面向高中生，内容应保持探索性、尊重和可撤回。它不进行心理诊断、能力排名、招生承诺或自动化录取判断。监护人、老师和学生可以共同核对结果；正式选择必须以本省考试院和高校章程为准。

## 危机表达

页面只对明显的自伤/无法保证安全表达显示固定支持提示，建议立即联系可信任成年人、老师或当地紧急服务。模型输出不能替代专业心理、医疗或危机干预；维护者不应把这条提示当作风险评估或报警系统。

## 删除与导出

“清除本机记录”会删除当前版本的会话、画像、同意、模式、票据和待同步回执，并刷新回星门。报告可以复制为纯文本或保存为图片；导出内容会带适用范围与免责声明，不包含 Authorization、TOTP 或内部思考。
